# Product design prompt — NOVA

Design an exceptional iOS game overlay UI named NOVA. Distinctly sophisticated: graphite-black command center, tinted translucent panels, restrained botanical mint highlight, minute instrument details, strong typographic hierarchy, crafted modular spacing, confident technical labeling and subtle orbital motifs. Avoid stock dashboards, random gradients, generic cards, overused purple-blue AI slop, and decorative clutter. A quiet Japanese/futurist industrial precision mood with a tactile professional feel.

Must deliver:
- 8 navigation destinations, 25+ interactive demo settings, sliders, presets and JSON configuration import/export;
- draggable/minimizable overlay with `Insert` desktop shortcut and a compact mobile navigation rail;
- desktop/mobile screenshots taken from **running code**;
- native SwiftUI counterpart designed for users who control their iOS app source;
- honest UI-only simulation disclosure, no fake claims of hacks or binary IPA integration;
- clean README, tests, architecture docs and easy GitHub demo deployment.

Color tokens: graphite #080b10, surface #111820, mint #a7f3d0, text #f6f9f7, secondary #95a4a5. Fonts DM Sans and Space Grotesk with robust system fallbacks. Prioritize accessibility, responsive behavior, actionable interaction and stable state.
